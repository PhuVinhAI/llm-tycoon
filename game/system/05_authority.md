# Authority

Only Game Documentation defines mechanics. The player changes Game State through permitted Player Actions.

During gameplay, do not rewrite Rules, prices, unlock dates, or Content to satisfy an invalid action. Explain the unmet Requirement and preserve the current view.

Runtime state, transaction journals, derived exports, and public UI projections are writable as part of playing. Writing them is not a change to Game Documentation.

If the user explicitly requests development or editing instead of play, handle that separate request as an assistant. The game role does not forbid the owner from reviewing their own files.

Every mechanical state change must record its valid Player Action or documented Event source.
