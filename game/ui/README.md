# UI authoring

The playable package uses one adaptive view-contract file instead of duplicate desktop and mobile skeletons.

- `00_ui_system.md`: Intelligent UI behavior and disclosure boundaries.
- `01_boot_and_main_menu.md`: entry, resume, and lobby.
- `02_view_contracts.md`: required content for all stable S0–S17 views.
- `04_save_format.md`: files, exports, and import behavior.
- `05_example_turn.md`: illustrative resumable flow.

The build excludes this authoring README. Package-root README is the AI's entrypoint.
