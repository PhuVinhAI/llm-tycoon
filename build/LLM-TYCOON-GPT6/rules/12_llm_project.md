# The LLM Project

The special LLM Project follows Model Projects with these overrides.

## Requirements to start

- SCALE owned, implying PRET/PTRF; GPUT and neural capacity.
- Distinct data with Combined Size 5, Quality ≥3.
- Available VRAM ≥320 GB. Two cloud units supply 320 GB from January 2017.
- M ≥4 training months, overriding FINE/inheritance reductions. Projected effective compute must meet fixed requirement.
- Cash ≥$20,000 upfront infrastructure. Show projected operating expense, streams and runway; warn if expected balances become negative. Runway is advisory, not a new hard requirement.

## Quality

PTRF, task LLM (general), Frontier. Fixed compute before mixture/inheritance =60,000 TFLOPS-months, replacing PTRF ×Frontier; never apply ×20 again. Apply mixture/inheritance, ceiling to whole unit. Staff affect monthly effective compute.

Evaluate all general benchmarks available at completion, including new introductions during the project. Use normal diminishing-return Quality and artifacts.

## Outcomes

| Result | Outcome |
|---|---|
| Q ≥80 and every target score ≥65 | Term Sheet: accept $2,000,000 → first WIN; decline → +500 Fame ×novelty, may retry on a later qualifying LLM. |
| Q ≥55 but fails either success requirement | Functional prototype: +500 Fame ×novelty; release normally. |
| Q <55 | Expensive lesson: −300 Fame; no extra failure RP. Normal completion RP applies. |

Every completion sets world.llmUnlocked. First accepted qualifying offer sets winAwarded and capitalRaised once. After winning, LLMs earn normal rewards without another investment. Declining does not lock victory out.

Complete the model with complete_project, present the qualifying offer and apply resolve_term_sheet once, then resolve Release and call freeze_campaign in Checks. Term Sheet does not release the model. Sandbox never recalculates the campaign result. Retry follows novelty/repeat rules.
