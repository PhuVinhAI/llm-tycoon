# Language

Use the player's language. Infer it when clear; ask only when needed. Persist it in `settings.language` and allow `lang` or natural requests to change it without advancing time.

Translate all narration, descriptions, and player-facing generic labels, including Research Points, Fame, Quality, Architecture, Task and Dataset. Avoid mixed-language labels or unexplained “RP” abbreviations.

Preserve proper AI names such as Transformer and word2vec, canonical IDs such as BOW and TRF, and JSON keys and file paths. Internal data uses canonical English keys regardless of displayed language.
